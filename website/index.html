Growovo

给产品事实和一个增长目标，它自己定策略、自己执行，每天交付业务结果。

开源 MITCLI / MCP / Agent Skillv0.14.0

这是什么

Growovo 面向独立开发者与一人公司：你把产品事实和一个增长目标交给它，它自己定策略、自己执行，每天交付业务结果——发布多少条、日均曝光多少、新增多少关注者。策略、计划、周报都是中间产物，不是交付物。

全自动的前提是平台可自动执行。第一期只承诺 X + Email（X 为 PROVEN，Email 为 PORTED）；GitHub、Reddit、Hacker News、LinkedIn 需人工首跑解锁；小红书、知乎等人工渠道只出作业单，不计入自动发布量。

只承诺三件可核验的事

承诺含义
执行量账本 committed 逐条可查
真实读数每天落粉丝与曝光，截图留证、带证据级别
闭环责任完成率驱动调量建议、供给缺口提前报警、异常停车待人工裁决

不承诺平台算法给多少曝光，也不把未验证渠道包装成全自动。

常见问题

能全自动发哪些平台？

第一期只有 X 和 Email（X 为 PROVEN，Email 为 PORTED）；GitHub、Reddit、Hacker News、LinkedIn 需要人工首跑一次才解锁；小红书、知乎这类人工渠道只出作业单，不计入自动发布量。用 mkt grow platforms 随时查看当前状态。

会不会把我的账号搞封？

只用于你拥有、或被明确授权操作的账号。发送前有授权闸门和 dry-run，可以先看它打算做什么再放行；平台规则之外的路径不提供绕过。同时明确：不承诺平台算法给多少曝光。

和定时发帖工具有什么区别？

定时发帖工具执行你写好的内容；Growovo 从产品事实和增长目标出发，自己定策略、排计划、执行，并把执行了多少、读数是多少落成可核验的账本。策略和周报是中间产物，交付的是每天的业务结果。更细的对照见对比页。

它说的结果，我怎么核实？

三样都可查：账本里每条执行记录逐条可查；每天落粉丝与曝光读数，截图留证、标证据级别；mkt demo 零网络零账号，本地一秒跑完完整闭环。反例也公开：上面的发布尸检就是一次 0 新增 star 的真实 campaign。

要花钱吗？

工具本身 MIT 开源，没有付费版。运行消耗的本机资源与模型调用按你自己的环境计。

出异常了怎么办？

异常停车待人工裁决，不会自行硬闯；完成率驱动调量建议；供给缺口提前报警，不会等用完了才说。
