OVO / Prove Anything：Agent 说“完成了”，仍需独立复核。Prove Anything 是族级结果证明协议候选；Verified Capability Factory（VCF）只是研究候选，不是 Growovo 当前依赖。Growovo 可独立使用，执行回执、有效回复、激活与成交继续分层，不能合并成“增长已证明”。

这是什么

给 Growovo 产品事实、目标受众和允许执行的动作。它检查待发内容，把已授权的动作排入队列，并记录执行回执。邮件发送结果不明时会停下等人核对。回复、激活和成交分别看实际记录。

全自动的前提是平台可自动执行。第一期只有 Email 可承诺无人值守自主执行；X 的所有非 API 网页脚本写都拒绝，只保留只读、dry-run、草稿与人工交接，自动写需接符合规则的官方 API；GitHub、Reddit、Hacker News、LinkedIn 需人工首跑解锁；小红书、知乎等人工渠道只出作业单，不计入自动发布量。

只承诺三件可核验的事

承诺含义
执行量账本 committed 逐条可查
真实读数每天落粉丝与曝光，截图留证、带证据级别
闭环责任完成率驱动调量建议、供给缺口提前报警、异常停车待人工裁决

不承诺平台算法给多少曝光，也不把未验证渠道包装成全自动。

一个具体任务：一次成功交付，和三次被闸门拦下的执行

输入是一个计划（demo-p0）、一个 campaign 和四个样例动作。三个可执行条目进入获批队列；含占位符的坏样本留在审批范围外，单独演示拒绝。下面是 mkt demo 的真实输出，零网络、零账号，每次运行重建沙盒，本地一秒内可复现：

步骤发生了什么结果
计划校验schema、beachhead、能力矩阵、是否超过内核日预算PASS（获批队列 3 条，日预算 100）
人审闸门campaign 属于计划 demo-p0，human_approved=false拒绝执行并停车——人审是执行前置条件
模拟人审批准mkt plan approve：署名 + 计划指纹 + 审批事件，写入 human_approved=true放行；后续写路径仍在沙盒里跑，不代表真实授权
成功投递d-000 过门禁 → 回读一致 → 离线发送（demo-memory，进程内内存）→ committed；账本补一张 L1 凭证1 条 committed，可逐条回查
三道拦截d-001 干跑未发送；d-002 占位符残留被门禁拒绝；d-003 回读不一致主动失败1 条 dry-run · 1 条 rejected · 1 条 failed，全部留痕
账本与日结果卡4 条终态与预期一致；日结果卡只读账本与三层凭证发布量 1（计划 1）；L1 有记录；L2/L3 为 UNKNOWN，不写 0

这个示例同时说明它交付什么、在哪停下：一条完整成功路径（门禁 → 回读 → 离线发送 → committed → 日结果卡），以及三处拦截（人审没通过、内容有占位符、发出去后读不回来）。发送是进程内内存模拟（demo-memory），没有任何外部发送；这里的 committed 只证明离线适配器已记录动作，不代表平台回执或转化；日卡里的 L2/L3 保持 UNKNOWN，不把未知写成 0。tests/test_demo.py 把「成功 + 三种拦截 + 可重复跑」固定成了回归测试。

常见问题

能全自动发哪些平台？

第一期只有 Email 可承诺无人值守自主执行；X 的所有非 API 网页脚本写都拒绝，只保留只读、dry-run、草稿与人工交接，自动写需接符合规则的官方 API；GitHub、Reddit、Hacker News、LinkedIn 需人工首跑解锁；小红书、知乎等人工渠道只出作业单，不计入自动发布量。用 mkt grow platforms 随时查看当前状态。

会不会把我的账号搞封？

只用于你拥有、或被明确授权操作的账号。发送前有授权闸门和 dry-run，可以先看它打算做什么再放行；平台规则之外的路径不提供绕过。同时明确：不承诺平台算法给多少曝光。

和定时发帖工具有什么区别？

定时发帖工具执行你写好的内容；Growovo 从产品事实和增长目标出发，自己定策略、排计划、执行，并把执行了多少、读数是多少落成可核验的账本。策略和周报是中间产物，交付的是每天的业务结果。更细的对照见对比页。

它说的结果，我怎么核实？

三样都可查：账本里每条执行记录逐条可查；每天落粉丝与曝光读数，截图留证、标证据级别；mkt demo 零网络零账号，本地一秒跑完完整闭环。反例也公开：上面的发布尸检是一次 0 新增 star 的真实发布实验，当晚绕过了账本——连失败都记不全，正是我们要修的问题。

要花钱吗？

工具本身 MIT 开源，没有付费版。运行消耗的本机资源与模型调用按你自己的环境计。

出异常了怎么办？

异常停车待人工裁决，不会自行硬闯；完成率驱动调量建议；供给缺口提前报警，不会等用完了才说。
