## 三、战术手册（怎么在四周内把一条渠道跑起来）

| 文件 | 适用 | 依据 |
|---|---|---|
| [Reddit 意图信号 · 四周](战术/reddit-意图信号-4周.md) | 产品已有可跑版本、用户 0–50 | Askovo 2026-11-03 研究：单渠道连续四周、每周 ≥20 条有效触达 |

**战术手册和平台手册的区别**：平台手册告诉你"这个平台是什么"，战术手册告诉你"明天几点做什么、第几天跟谁、跑完怎么判定"。一次只跑一条渠道。

---

## 四、写新手册前必读

1. **先研究，再下结论**。没有官方原文或真实案例的，写"未核实"。
2. **第 11 节必须有**（发完之后怎么跟）。最初 20 本里有 18 本漏了这节，这就是"发布一次就没声音"的病因；2026-11-03 已全部补齐。
3. **业务语言**。不要证据编码、不要打分表、不要"要提供有价值的内容"这种废话。
4. **一次只推荐 1–2 个平台**。同时推六个平台的报告，等于没有判断。
