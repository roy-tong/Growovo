# 战术手册：X 高价值回帖 · 连续四周

> 建册：2026-11-14 · 适用：产品已在 X 有账号、粉丝少、原创帖没人看的阶段
> 依据：2026-11-14 战术研究综述（经验语料库约 620 篇 + 外部研究）。结构化参数在
> `core/tactics.py`（`x-reply-guy`），执行记录与纪律检查用 `mkt tactic` 命令组。
> 触发事实：**自家实测，回帖的触达明显大于原创帖**——这不是技巧，是机制。

---

## 为什么回帖比原创帖有用

一句话：**你的原创帖最多被你的粉丝看到，而你的粉丝接近零；一条有信息增量的
回复排进热帖评论区，会被那条帖子的全部读者看到。** 位置按内容质量和速度分配，
不按粉丝量分配。

证据（都有出处）：

| 事实 | 出处 |
|---|---|
| X 算法里回复的权重约是点赞的 9 倍，链接点击只有 0.1 倍 | X 2023 开源算法分析（dev.to/axrisi） |
| 300 个从小做到一万粉的账号，84% 主要靠回帖 | Teract 追踪数据（teract.ai） |
| 一位创始人 200 天 0→13k 粉，几乎全靠回复（月回复峰值 1.2 万条，仅 1 条被判垃圾） | 语料（reddit/68c4fdb88d） |
| 每天回 15–20 条，带来每周 100–200 次主页访问、20–40 个新粉 | Teract 追踪数据 |
| 5 分钟内回复的主页访问是慢回复的 4.2 倍 | 同上 |
| 零粉时只发原创帖"像在空房间里说话"，先回帖攒到初始受众再发原创 | r/SaaS、HackerNoon 共识讨论 |

代价也说清楚：这是**手艺活**，每天 20–45 分钟；用脚本批量回复是封号路径
（见第 5 节红线）。

## 第 1 周（准备周）：只建清单，不行动

### 目标账号清单（10–15 个）

选**自己粉丝量 5–20 倍**的账号：

| 账号体量 | 回复效果 | 结论 |
|---|---|---|
| 50 万粉以上 | 帖子首小时几百条回复，你的回复被淹没 | 不选 |
| 自己的 5–20 倍（如你 500 粉，选 2.5k–10k 粉） | 能排进评论区前 10–20 位 | **选这个区间** |
| 和自己差不多或更小 | 没流量 | 不选 |

三类目标都要有：
1. 领域里活跃的创作者（内容型目标）
2. **正在求推荐/抱怨现有工具的人**（意图型目标，转化率最高）
3. 做相邻产品的账号（他们的读者就是你的读者）

操作：建私密列表（List）→ 全部开小铃铛 → 每天看 3–5 次。
清单每周换一次：涨太快的账号移出，补新的进来。

### 自查账号承接力

主页必须有：一句说清你做什么的简介、3–5 条能看的原创帖、固定一条代表作。
**评论区来的人点进主页没东西可看，就不会关注。** 原创帖是转化层，不是获客层。

## 第 2–3 周（执行周 + 跟进周）：每天 15–20 条

### 只回什么样的帖子

| 规则 | 数值 | 为什么 |
|---|---|---|
| 帖子发布时间 | 30 分钟内（5 分钟内最好） | 前 30 分钟的互动速度决定分发，早回复被留在前排 |
| 帖子已有回复数 | 少于 20 条 | 竞争少，你的回复能被看见 |
| 长推文串 | 只回第一条 | 评论区流量集中在第一条 |
| 同一账号 | 每天最多 2 条 | 每条都回显得急切，会被屏蔽 |

### 回什么：七种内容公式

每条 1–2 推长，**观点独立成立**（不依赖原文也能看懂）：

| 公式 | 效果参考 | 一句话示例 |
|---|---|---|
| 数据型 | 互动约 3.2 倍 | 补一个具体数字："我们测过 300 个号，84% 靠回帖起来的" |
| 经验型 | 主页转化约 2.8 倍 | "我们踩过这个坑，实际是……" |
| 反共识型 | 互动约 4.5 倍 | 礼貌反驳 + 证据（**不做人身攻击**） |
| 提问型 | 容易引作者回应 | 问一个有质量的问题（作者回你是强信号） |
| 洞见型 | — | 给一个新角度 |
| 放大型 | — | 延展作者论点、补案例 |
| 资源型 | — | 先给上下文再给参考 |

带图的回复互动约 4 倍（小截图/数据图）。

### 绝对不做

- **回复里永不放链接**（链接是评论区第一垃圾信号，算法只给 0.1 倍权重）
- 不推销、不提产品（除非对方明确问起且相关）
- 不发"好文！"这类空话——等于零，还拉低你主页的观感

### 节奏配比

**70% 时间回帖 + 30% 时间原创**：每周 3–5 条原创帖做转化层；对自己收到的
每条回复 1 小时内全回。第 3 周不加新量，把第 2 周回应过的人跟完。

## 第 4 周（判定周）：看三个数

| 指标 | 参考线 | 数据来源 |
|---|---|---|
| 主页访问 | 每周 100–200 次 | X 分析面板 |
| 新增粉丝 | 每周 20–40 个 | 同上 |
| 回应率（有人回你/总数） | 10% 观察、3% 继续看 | 自己记录 |
| 被删/被折叠 | 超过 15% 是安全异常 | 自己记录 |

判定三选一（人判，工具只给数）：**继续**（有互动且在涨）/ **调参**（换目标
清单或换公式）/ **停**（四周 80 条样本后仍无互动，先查需求匹配，不自动换渠道）。

## 5. 红线（引擎里已强制，人也别绕）

| 红线 | 后果 |
|---|---|
| 每小时超过 20 条回复 | 垃圾行为特征，回复被折叠 |
| 回复内容高度雷同 | 被判模板回复 |
| 同一账号每天 3 条以上 | 被屏蔽（mute） |
| 回复带外链 | 第一垃圾信号，算法天然压低 |
| 用脚本批量生成/发送 | X 明确反对自动化，封号路径 |
| 回复被折叠后继续高频 | 先停 24 小时，恢复期每天 5–10 条 |

## 6. 用引擎跑这套（mkt tactic）

```bash
mkt tactic show x-reply-guy                    # 看全部参数与证据
mkt tactic start xrg-1 --tactic x-reply-guy    # 开四周执行记录
mkt tactic check --tactic x-reply-guy \
  --target tweet:https://x.com/xxx/status/123 \
  --text "回复草稿……" --post-age 4             # 发出前检查（禁链/占位符/超窗）
mkt tactic draft xrg-1 --target ... --text ... # 候选入池（带上限与重复检查）
mkt tactic export xrg-1 --campaign xrg-1       # 导出队列，走既有审批与发送路径
mkt tactic log xrg-1 --sent 18 --replied 2     # 每日记账
mkt tactic show-run xrg-1                      # 进度 + 纪律提醒
mkt tactic verdict xrg-1                       # 四周判定（人下结论）
```

纪律（日上限 20、每目标 2、每小时 20、禁链、禁重复话术、回帖 30 分钟窗）
在 `core/tactic_run.py` 里强制：候选阶段直接拒绝，已发生的超限记违规并在
判定时汇总。
