# 少数派

> 一句话：中文效率工具/数字生活的深度测评社区——Matrix 写作社区 + 编辑精选制，读者是"愿意为好工具付费"的高价值人群。 · 研究日期：2026-11-03 · 官方口径：Matrix 机制部分已核（站内官方栏目），稿费细节未核 · **自家实测：无**

## 1. 这里是什么地方
**谁在这里**：效率工具爱好者、Apple 生态用户、知识工作者；付费意愿与工具鉴别力都高。
**来干什么**：读深度测评与工作流文章（"笔记应用怎么选"类内容的主场）；选工具前先来搜。
**GTM 角色**：**信任 + 高质量长尾**。一篇被编辑推荐的测评=工具圈的背书；读者画像与"效率工具"产品完全重合。

## 2. 内容怎么被看见
- **分发**：编辑精选（首页推荐/《社区速递》栏目）+ Matrix 社区流；"少数派会不定期挑选 Matrix 最优质的文章进行展示和推荐"（[Matrix 栏目](https://sspai.com/post/82869)，**站内官方口径**）。
- **曝光持续**：文章长尾极强（站内搜索+Google 权重），一篇好测评持续引流数年。
- **新手**：申请 Matrix 写作权限 → 签署 **Matrix 共创计划** → **独家发布**（官方流程，**已核**）。

## 3. 官方规矩
- **Matrix 共创计划**：成为作者需签署；文章在少数派独家发布（**已核存在**，条款细节未核）。
- **栏目要求实例**：「新玩意」投稿需标题加前缀、**至少 800 字产品介绍 + 2–3 张图**（**已核**，同上来源）。
- **稿费**：被推荐/精选的文章有稿酬；**具体标准未核实，以官方说明为准**。
- **拒稿**：无公开的拒稿规则清单 [**未核实**]；从栏目要求推断：非独家、软文明显、深度不足是常见原因 [**推测**]。

## 4. 真实打法（效率工具/SaaS 主场景）
1. **第一步**：先读 20 篇 Matrix 高赞文（如[笔记应用怎么选](https://sspai.com/post/57140)），摸清"少数派腔调"——真实使用数周+横向对比+工作流整合。
2. **写作**：以"我的 XX 工作流"切入，你的产品放进对比矩阵（含竞品，客观评分——软文感是拒稿主因 [**推测**]）。
3. **节奏**：月 1–2 篇深度稿的产能就够；重质。
4. **见效**：编辑推荐后 1–3 天脉冲 + 数年长尾。失败的样子：800 字凑数、只写自己产品、无截图无数据。

## 5. 死路
1. 一稿多投/非独家（违反共创计划）。2. 软文（编辑与读者鉴别力双高）。3. 洗稿他人测评。4. 凑字数投「新玩意」（800 字+配图是下限不是目标）。5. 把 Matrix 当 SEO 农场铺量（精选制下铺量无效）。

## 6. 这里的人怎么说话
克制、截图密、参数准；"我的需求/我的方案"框架；承认产品缺点是加分项。忌讳：营销形容词（"颠覆""革命性"）、无使用痕迹的评测。好开头（[模式还原]）："换了 4 个笔记应用之后，我把选择标准写成了这篇。先说结论：没有最好的，只有匹配工作流的。" / "这个工具我用了 87 天，付费了，但也退订过一次。原因如下。"

## 7. 账号与节奏
Matrix 作者身份是核心（申请制）；月更即可；时段无意义（编辑制）。资产：Matrix 作者页、精选记录、稿酬等级。

## 8. 风控与踩线
编辑审核前置（发表即已过审）；违规=取消共创资格 [**推测，条款未核**]。被拒：按编辑意见改稿重投 [**社区经验**]。

## 9. 怎么衡量有用
能拿到：文章阅读、评论、点赞（作者后台）。拿不到：出站归因（自建 UTM）。被问到：评论区"和 XX 比怎么样/有没有 Windows 版"。误读：阅读量低=失败（少数派看长尾，工具类文章 6 个月仍在引流是常态 [**社区观察**]）。

## 10. 适不适合
适合：效率工具、Apple 生态周边、知识工作类 SaaS；能写深度中文长文的团队。不适合：非工具类、海外 only、无写作产能。搭配：少数派深度测评（信任+长尾）→ 公众号沉淀 → 即刻/小红书切片传播。
