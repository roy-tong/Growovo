# 海外长尾平台速览（P2）

> 交接单 §5.15 规格：每平台四问。 · 研究日期：2026-11-03 · **轻量速览，未逐平台核官方原文**；升级为正式手册前不做结论引用。 · 自家实测：仅注明处

## YouTube
**谁**：全球 + 技术教程搜索者（"YouTube 是海外第二大搜索引擎"为常识说法）。**怎么被推**：搜索+推荐；教程长尾极强。**禁什么**：虚假互动（买观看/订阅）违反官方政策 [政策存在，未核原文]；AI 内容标识按各国法规。**值不值得**：**有视频产能才做**——一条好教程=数年长尾；文字团队用"教程视频"最低配（录屏+字幕）即可进场。**判定：B站的海外镜像逻辑，产能允许则做**。

## TikTok
**谁**：全球年轻用户。**怎么被推**：算法流量池，完播驱动。**禁什么**：买量与虚假互动 [未核细则]。**值不值得**：消费级 AI 工具的"效果钩子"有 viral 机会；devtool 无人群。**判定：消费级可选，工具类不做**。

## Google SEO（自有站）
**谁**：主动搜索你的品类词的人——**这是资产不是平台**。**怎么被推**：内容质量+外链+E-E-A-T；周期 3–6 个月起 [行业常识]。**禁什么**：垃圾外链/关键词堆砌会被惩罚（Google Search 政策 [未核原文]）。**值不值得**：**所有产品的地基**：落地页/文档/blog 做扎实，其他平台的搜索权重最终汇到这里。Reddit/Stack Overflow 帖在 Google 权重高（见对应手册），是 SEO 的外部放大器。**判定：必做（作为目的地，不是渠道）**。

## Newsletter 投稿（TLDR / Console / Latent Space 等）
**谁**：订阅制技术读者，编辑部筛选。**怎么被推**：无算法——编辑人工选。**禁什么**：各报自成规则 [未核实]。**值不值得**：一次收录=千级到万级精准曝光 [行业量级常识]；**自家实测：TLDR 投稿口 2026-10 实测 404 关闭**（Verovo 复盘死路记录）——投稿渠道会失效，投前先验链接。**判定：值得，但逐报验证入口存续**。

## 软件目录站（G2 / Capterra / AlternativeTo）
**谁**：明确带"找软件/换软件"意图的采购者——G2 尤其是B2B 决策链一环。**怎么被推**：站内搜索+分类榜+评论数排序。**禁什么**：刷评论高压线（G2 明令 [未核原文]）；未披露的激励评论。**值不值得**：**B2B 产品必做**：上架+首批真实评论（求评式 1:1 模式平移——Verovo 的 5.3% 求评邮件可直接复用来邀请真实用户留评）；免费档位即可起步。**判定：B2B 必做，devtool 视品类**。

## Stack Overflow
**谁**：程序员问答，专业度最高的英文技术社区。**怎么被推**：问题页投票+Google 权重（SO 答案常年霸技术搜索首位）。**禁什么**：**明文禁止在答案中推广自家产品**（帮助中心 self-promotion 条款 [未核原文，规则存在是常识]）；签名链接滥用被 flag。**值不值得**：**答技术问题建立专家身份≠推广**——产品名进不了答案，但 SO profile 与高赞答案是最硬的技术背书；Tags/Teams 另有商业产品。**判定：以专家身份参与（长线），不作为推广位**。

## Discord / Slack 社区
**谁**：按主题聚集的即时聊天社群（开源项目/工具的用户群）。**怎么被推**：无公域——**自建=产品社群，他建=目标客群聚集地**。**禁什么**：各 server 自治规则；服务器内刷广告=秒踢。**值不值得**：**自建 Discord/Slack 是 devtool 的用户运营标配**（GitHub README 挂入口）；混别人的 server 只能真诚参与。**判定：自建做用户沉淀；他建以居民身份参与**。

## Bluesky / Mastodon
**谁**：去中心化社交流亡者——技术人/记者浓度高，规模远小于 X。**怎么被推**：关注时间线为主（Bluesky 有 feeds 机制）；无强算法。**禁什么**：各实例自管（Mastodon）；垃圾信息举报文化强。**值不值得**：**增量实验场**——技术圈浓度高、噪音低，发 build in public 有真实同行互动；天花板低（受众基数小）。**判定：X 的低成本补充，每周少量同步即可，不投主力**。

---

**P2 海外总结**：SEO（目的地）与软件目录站（B2B）是"必做"；YouTube/Discord 按产能标配；Newsletter 投稿逐报验入口（自家 404 实测在前）；TikTok/SO 有明确边界；Bluesky/Mastodon 轻量补充。
