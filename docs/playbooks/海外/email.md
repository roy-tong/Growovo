# 邮件 / 一对一外联

> 一句话：唯一能直接说给一个人听的地方，也是唯一被自家数据证明"做对了就有用"的地方 · 研究日期 2026-11-03
> 官方口径：不适用（自有通道）· **自家实测：最强一条**（Verovo 209 封求评 → 11 次实质回复 ≈5.3%；传统冷问 0/26）

## 1. 这里是什么地方

**谁在这里**：你选中的那一个人。没有算法、没有推荐、没有围观，只有他愿不愿意读。

**他们来干什么**：清邮箱。默认动作是划过去，平均给每封 3 秒。

**在 GTM 里的角色**：**关系渠道**。它不制造注意力，它把已经存在的注意力变成一次对话。

## 2. 内容怎么被看见

- **分发靠什么**：进收件箱（送达率）→ 主题行被点开（打开率）→ 前三句决定读不读。
- **什么会被打开**：具体到"他"的主观行。抽象主题（"关于增长的一些想法"）直接删。
- **曝光时长**：发出后 24–48 小时；之后基本没人翻。
- **新域名的难度**：极高。没有 SPF/DKIM/DMARC、没有发送历史，直接进垃圾箱。

## 3. 规矩（自有通道，但平台会替你管）

| 规则 | 说明 |
|---|---|
| 退信率 >5% | 立刻停，清洗名单——继续发会毁掉域名信誉 |
| 同域 ≤5/日 | 一次发几十封到同一家公司，会被判定为骚扰 |
| 必须有退订 | 多数司法辖区法规要求；没有是法律风险 |
| 不群发 | 不是道德问题：群发的回信率实测为 0 |

## 4. 真实打法

**唯一被验证有效的：求评式 1:1。**
- 把对方放在专家位（请他指出你的问题）
- 钩子用他自己公开的数字
- 结尾是一个真问题

**自家数据**：209 封求评 → 6–11 次实质回复（5.3%）；对照冷问句式 26 封 → 0。
**反面**：批量个性化 182 封 55% 退信；$990 冷邮件 40 发 0 回。

**见效周期**：当天到一周。

## 5. 死路

| 做法 | 为什么没用 |
|---|---|
| 群发 | 回信率实测 0；且毁域名 |
| 第一句报价 | 对方还没理解你是谁 |
| 一封邮件讲三个产品 | 没人读第二段 |
| 附件带可执行文件 | 直接进垃圾箱 |
| 用 Web UI 自动化批量发 | 自家 449 封空正文事故，通道永久关闭 |

## 6. 这里的人怎么说话（人味）

**这是唯一"一封只写给一个人"的渠道，所以人味就是全部。**

- 前三句必须证明你看过他的东西（引用具体一条）。
- 给一个立刻能用的东西，再谈自己。
- 结尾问一个他真的会回答的问题。
- 承认自己是作者，不要装用户。

**一眼假的信号**：称呼"尊敬的"、"我们致力于"、通篇讲公司、结尾"期待您的回复"。

## 7. 账号与节奏

- 自有域名 + SPF/DKIM/DMARC。
- 一天不超过 20 封，同域不超过 5 封。
- 时段：对方所在时区的上午。

## 8. 风控与踩线

| 检测 | 信号 | 改什么 |
|---|---|---|
| 退信率 | >5% | 停，清洗名单 |
| 投诉/垃圾举报 | 送达率骤降 | 降频，改成纯一对一 |
| 域名信誉 | 进垃圾箱 | 停发两周，重新预热 |

## 9. 怎么衡量有用

能拿到：送达、打开、回信、约到的对话。
拿不到：多少人看了没回。
"被问到"：对方回信问具体细节，或约时间。

## 10. 适不适合

适合：B2B、开发者工具、有明确人群的。
不适合：消费类、没有具体对象的。

## 11. 发完之后怎么跟

- 当天：有回信当天回。
- 第 3 天：对说"我看看"的人问一句"试了吗，卡在哪"。
- 第 14 天：没回的不要重复同一句，换一个角度给新东西。
- 第 45 天：最后一次，带一个真正的新东西；之后停。
