# X（Twitter）

> 一句话：最像"人"的地方，也最容易暴露你是"机器" · 研究日期 2026-11-03
> 官方口径：**未核**（Automation Rules 原文未抓取，标 [待核]）
> 自家实测：**有，而且是最残酷的一条**（Verovo：2 天约 199 条动作 → 0 个代码产物，2026-09）

---

## 1. 这里是什么地方

**谁在这里**：开发者、创始人、投资人、写 newsletter 的人、以及大量靠注意力做生意的人。技术圈的信息扩散主要发生在这里。

**他们来干什么**：看别人在做什么、参与争论、展示自己、偶尔发现新工具。**没有人在 X 上"找解决方案"**——他们在刷，不在搜。

**它在这门生意里的角色**：**扩散层，不是转化层**。一条好内容能被转几十次，触达上万人；但这些人接下来不会因为你说了什么就注册。他们的动作是：点进你的主页 → 点进仓库 → 也许 star 一下。

**这条要记牢**：X 的正确指标是"**有多少人顺着你走到仓库**"，不是"有多少人回复你"。自家分析得出的原话是：X 的正确 KPI 是 repo 访问/star 转化，不是回复数。

---

## 2. 内容怎么被看见

**分发机制**：关注关系打底 + 算法推荐。算法偏向：有互动（回复 > 转发 > 点赞）、发得新、有图/视频、作者是"活跃的人"。

**什么会被推**：
- 有明确观点的短帖（"我认为 X 是错的，因为……"）
- 具体的进展或数字（"这周我们处理了 12 万条，出错 3 条"）
- 有争议的话题（争论本身带来互动）
- 截图和演示（技术人很吃 GIF）

**曝光能持续多久**：极短。几小时。**但**如果被几个大号转发，能再续一天。长期价值几乎没有——没人会翻你三个月前的帖子（能被翻到的只有主页置顶和搜索结果）。

**新号有多难**：非常难。0 粉丝的号发帖，触达接近于零。冷启动阶段的唯一办法是**去别人帖子里说话**，不是自己发。

## 3. 官方规矩 [待核]

> 以下为已知边界，**原文未抓取核验**，用之前必须人工核一遍 Automation Rules 与 Platform Manipulation 政策。

| 规则 | 状态 | 要点 |
|---|---|---|
| 自动化限制 | [待核] | 允许通过官方 API 做部分自动化；禁止批量关注/取关、批量私信、伪造互动 |
| 平台操纵 | [待核] | 多账号协同刷互动属操纵，会被限制或封禁 |
| 内容政策 | [待核] | 仇恨、骚扰、虚假信息有明确边界 |
| AI 内容 | [待核] | 目前没有像 HN 那样的"禁止 AI 生成"明文，但有"不得冒充真人/不得操纵"的边界 |

**已知的现实**：X 有很强的反自动化机制（登录态检测、行为指纹、频率异常）。**用浏览器自动化去发帖，被识别是时间问题**，不是运气问题。

## 4. 真实打法

### 先说结论：X 能做什么、不能做什么

**自家实测（Verovo，2026-09，2 天）**：

| 指标 | 数字 |
|---|---|
| 总动作 | 约 199 条（1 条原创 + 189 条回复，其中约 97 条半自动量产） |
| 人类回应 | 3 条 |
| 模板族回复的回应率 | 约 1.5% |
| **深度技术评论的回应率** | **2 / 2 = 100%** |
| 代码/项目产物 | **0** |

**这组数字的含义**：模板化冷触达在这条渠道上基本等于零。而"针对特定的人、贡献特定的技术发现"是 **100%**。差了两个数量级。

### 有效的做法

**1. 针对具体的人的、具体的发现**（唯一被验证有效的）
不是你@他说"我们产品能帮你"，而是：看他最近在做什么、遇到什么问题，用你手上的真实数据回答他。

例：某人在抱怨 LLM 输出计数不准 → 你回："我们测过 5 个供应商的同一个 prompt，有 3 个在重试时会重复计数，复现步骤在下面。" 然后附上你的发现。不提产品。

**2. build in public**
每周发一条真实的进展：做了什么、数据多少、踩了什么坑。不推销，只记录。长期下来会有一批关注你的人——**但他们关注的是"这个人"，不是"这个产品"**。

**3. 有观点的短帖**
"我认为 X 这样做是错的，因为 Y。" 技术圈吃这套。观点要具体，能被反驳，别和稀泥。

**4. 演示型内容**
15 秒的 GIF，展示一个真实的使用场景。不需要解释，看了就懂。这类内容转发率最高。

## 5. 死路

| 做法 | 为什么没用 |
|---|---|
| **模板化冷回复**（批量评论别人的帖） | 自家 189 条里 ~97 条是这个，回应率 1.5%，零产物。而且这些号很快会被认出是机器人 |
| 批量私信 | 违反平台规则，且转化率接近于零 |
| 求关注/求转发 | 没人理，而且显得廉价 |
| 发链接为主的帖子 | 算法压外部链接，且看起来就是广告 |
| 多账号互捧 | 平台操纵，会被一起处理 |
| "求支持，我们上 Product Hunt 了" | 这是最招人烦的一类，且几乎必然被无视 |
| 用 AI 生成一堆"金句式"内容 | 这类内容在 2026 年已经泛滥，读者的免疫系统很强 |

**一条判断标准**：如果你的回复可以被复制粘贴到任意一个相似的帖子下面，那它就是垃圾。

## 6. 这里的人怎么说话（人味）

**语气**：短、具体、有观点、能自嘲。一句话能说完的别写两句。

**被尊重的表达**：
- 直接给结论："这个方案会在高并发下丢数据，我踩过"
- 给数字："12 个供应商里 4 个有问题"
- 承认不知道："这个我没测过"
- 自嘲："我又把生产环境搞挂了"

**一眼看出是机器/营销的信号**：
- 每条都以 "Great point!" / "This is huge!" 开头
- 每句都换行，像诗
- 通篇 emoji 🚀🔥💡
- 只有结论没有过程
- 每条都带产品链接
- 语气永远积极，从不批评任何东西

**好的帖子长什么样**（真实风格）：
> "spent 3 days chasing a bug that turned out to be a 2-character typo in a config key. the fix took 4 seconds. i'm fine."

> "we ran the same prompt through 5 providers. 3 of them double-count tokens on retry. here's the repro."

> "hot take: most 'AI agent' demos are just a for-loop with extra steps. i say this as someone who built one."

**忌讳**：
- 把 X 当客户群（在这里做销售是社交自杀）
- 蹭热点硬关联自己的产品
- 一天发十几条（会被当成刷屏，掉权重）

## 7. 账号与节奏

- **新号**：先花两三周去别人帖子里说有价值的话，攒一点辨识度，再开始发自己的。0 粉丝直接发推广 = 0 触达。
- **频率**：一天 1–3 条原创是上限。回复不限，但要有质量。
- **时段**：美东上午（北京时间晚上）最好。周二到周四活跃度高。
- **账号资产**：粉丝数、历史互动、被人认出来的程度。这个账号是要养几年的资产，别为一次推广毁掉。

## 8. 风控与踩线

| 手段 | 性质 | 说明 |
|---|---|---|
| 登录态与行为指纹 | 已知 | 浏览器自动化容易被识别（没登录、行为不自然、频率异常） |
| 频率异常 | 已知 | 短时间大量动作会被限流 |
| 平台操纵检测 | 已知 | 多账号协同、批量关注/取关会被处理 |
| AI 内容标识 | [待核] | 政策在变，用之前要核 |

**踩线信号**：帖子突然没曝光、被限制回复、登录被要求验证、账号被 shadowban（别人看不到你的回复）。

**被处理了怎么办**：
1. 立刻停掉所有自动化
2. 不要再试同一条路（验证会越来越严）
3. 换到官方 API 能覆盖的操作，或者转人工
4. 严重的话换渠道，不要在 X 上死磕

**一条铁律**：**不要用自动化去对抗检测。** 一次被封，账号资产清零，而且平台会记住设备。

## 9. 怎么衡量有用

**能拿到**：曝光数、互动数、主页访问、链接点击（你自己的追踪）。

**拿不到**：多少人看了没点、有多少人是真读者。

**"被问到"长什么样**：
- 有人私信问"这个能用在 X 场景吗"
- 有人点进仓库并 star
- 有人在评论里要文档/试用
- 有人引用你的帖子并加了具体评论

**常见误读**（自家踩过的）：
- **回复数 ≠ 有效**。189 条回复换来 3 条真回应，其中能算"推进"的是 0。
- **曝光大 ≠ 有用**。几千曝光可能一个 star 都没有。
- **互动多 ≠ 认同**。很多互动是争论。

---

## 10. 适不适合

**适合**：
- 创始人个人品牌（这是 X 唯一确定能做成的事）
- build in public 的长期记录
- 有观点、能持续输出的人
- 技术社区里"混个脸熟"

**不适合**：
- 直接获客（自家数据：0 产物）
- 冷启动快速起量
- 需要长篇解释的复杂产品
- 任何形式的批量触达

**搭配使用**：X 做"被看见"，GitHub 做"被采用"。X 上发的东西应该让人想点进你的仓库——如果做不到这个动作，就是自嗨。
