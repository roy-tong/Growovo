# 平台手册 · 模板与写作规范

> 每一本平台手册都按这个模板写。**不合规的手册不算交付**。
> 建模板：2026-11-03 · 适用：国内外全部 GTM 平台

---

## 一、这份手册是给谁看的

给**明天就要动手的人**看的。不是给投资人或同行看的。

判断标准只有一条：**一个没做过这个平台的人，看完能不能直接开始干，并且知道自己会不会踩雷。**

---

## 二、写作纪律（违反即重写）

### 1. 用业务语言，不用行话和编码

| 不要写 | 要写成 |
|---|---|
| E2 级证据 / validated / needs-validation | "有人这么干过，结果是……" / "目前只是听说" |
| S3 信号 / CTR 3.2% | "有人主动来问" / "一百个人看到，三个点进来" |
| R=3 A=2 C=1 | "这个平台的人正在找这类东西，但排名不受你控制，而且不许自动发" |
| operator 47 分钟 | "我得花 47 分钟" |

### 2. 每个事实都要能追到出处

- 官方规则：给原文引用（英文引原文 + 中文解释）+ 链接 + 抓取日期
- 他人经验：给到具体帖子/文章，能说清是谁、什么时候、什么结果
- 自己的实测：写清楚做了什么、结果如何

**查不到出处的，写"未核实"，不许写成事实。** 猜测要标明"推测"。

### 3. 分清楚三种东西

- **平台说的**（官方规定）
- **大家说的**（社区经验，可能过时或片面）
- **我们做的**（自家实测）

三者冲突时，以"我们做的"为准，但要写明为什么。

### 4. 不写正确的废话

"要提供有价值的内容""要真诚互动"——这类话一句都不要。每条建议都要具体到**能照着做**：几点发、发多长、第一句说什么、什么时候收手。

---

## 三、手册结构（十一节，缺一节不算完成）

```markdown
# [平台名]

> 一句话：这个平台是干什么的 · 研究日期 · 官方口径是否已核

## 1. 这里是什么地方
- 谁在这里（说人话：什么人、大概什么水平、什么心态）
- 他们来干什么（具体到时刻和任务，不是"用户画像"）
- 这个平台在 GTM 里的角色（发现 / 信任 / 转化 / 传播 / 沉淀）

## 2. 内容怎么被看见
- 分发机制：算法推荐 / 投票 / 编辑挑选 / 搜索 / 关注关系，各占多少
- 什么内容会被推上来（给真实例子，说清为什么）
- 曝光能持续多久（一天？一周？还是长期被搜到）
- 新手有多少初始曝光（新号/新内容冷启动有多难）

## 3. 官方规矩（原文 + 日期）
- 明令禁止的行为（逐条，引原文）
- 内容要求（原创、披露、AI 相关）
- 账号要求（注册、实名、信誉门槛）
- 违规的后果（删帖 / 限流 / 封号 / 连带）

## 4. 真实打法（按产品类型分开写）
对每一类产品：**有效做法 + 具体例子**
- 开发者工具 / 技术产品
- SaaS / 效率工具
- 消费品 / 内容产品
- 一人公司 / 独立产品

每一条打法必须写清：第一步做什么、需要什么账号、大概多久见效、失败的样子是什么。

## 5. 死路（看着有理其实没用）
- 具体反例 + 为什么没用 + 有没有人被处罚

## 6. 这里的人怎么说话（人味）
> 这一节是手册的灵魂。同样的内容，语气不对就是广告，语气对了就是分享。

- 语气与句式：长句还是短句、正式还是随意、能不能自嘲
- 格式习惯：分段、图片、链接、代码块、标题写法
- 被尊重的表达：什么样的内容会被点赞/收藏/转发
- 一眼看出是"营销"的信号：列出来，逐条避免
- 黑话、梗、忌讳：说错会怎样
- 一个好的开头长什么样（给 2–3 个真实例子）

## 7. 账号与节奏
- 新号能不能直接发，要不要养号，养多久
- 一个账号一周发几次算正常，几次算刷屏
- 什么时段发（当地时间 + 北京时间）
- 账号资产怎么积累（粉丝、信誉、历史内容）

## 8. 风控与踩线
- 平台怎么识别 AI 内容 / 自动化 / 刷量（已知 + 推测分开写）
- 踩线的信号（内容下沉、被删、限流、收到通知）
- 被处理了怎么办（申诉路径、能不能救、什么动作会让情况更糟）

## 9. 怎么衡量有用
- 能拿到什么数据（曝光、点击、互动、转化）
- 拿不到什么数据（说清楚盲区）
- 什么算"被问到"（这个平台的"有人主动来问"长什么样）
- 常见的数据误读

## 10. 适不适合
- 适合什么类型的产品、什么阶段
- 不适合什么（说清楚，别为了凑数推荐）
- 与哪些平台搭配使用

## 11. 发完之后怎么跟
> 这一节是 2026-11-03 加的。原因：前 20 本手册里有 18 本完全没写"发完之后"，
> 结果是把"发布一次就没声音"这个病原样复制了一遍。通用方法见 `00-跟进机制.md`，
> 这一节只写**这个平台特有的**跟法。

- 场内怎么跟（评论区/私信/弹幕/群）——这个平台的"回话"长什么样
- 场外怎么转（转到什么渠道、第一句说什么、什么不能提）
- 这个平台的跟进禁忌（做什么会被当成骚扰）
- 从"被看到"到"被问到"通常要几步、几天
- 一个具体的最小节奏（第 3 天做什么、第 7 天做什么、第 45 天做什么）
```

## 四、完成自检

交稿前逐条打勾：

- [ ] 十一节齐全，没有"待补充"占位
- [ ] **第 11 节写了平台特有的跟进方式**（只写"要多互动"不算，要具体到第几天说什么）
- [ ] 每条建议都具体到能照着做
- [ ] 官方规则有原文 + 链接 + 日期
- [ ] 标清了哪些是"平台说的"、哪些是"大家说的"、哪些是"我们做的"
- [ ] 第 6 节「人味」写了真实例子，不是形容词
- [ ] 第 5 节「死路」有具体反例
- [ ] 全文没有证据编码、没有打分表、没有行话
- [ ] 一个外行读完能直接开始
