# 0.14.0 整合复核

范围：11 月 14 日 dsh、zcode 与 Codex 各轮迭代，包括晚间登录态门禁、提前备货、82 条战术、推荐器、只读监控及网站分支。

| 发现 | 整合后的行为 |
|---|---|
| 目标库评分与自动发现脱节 | 自动 KOC 排序复用信任评分；垂直证据和独立语义审核继续生效 |
| 商单未知被解释为零，阶段变化混入互动 | 未知字段明确标记；阶段推进需证据；按事件、时间窗及 KOC 人群统计 |
| 陈旧队列占库存、未来备货跨周失效 | 陈旧内容不阻挡补货，各备货日读取所属周的配额 |
| 推荐器混入显式范围外渠道 | 显式渠道优先；目标编译保存白名单风险的建议组合，不扩大发送权限 |
| 无重定向即判已登录 | 只有目标站点的已登录界面标记才能确认；不明状态不能放行 |
| CDP 连接依赖开发机驱动补丁 | 支持时使用 Playwright 原生 no_defaults，保留已有浏览器上下文 |
| 空页、脚本变动被当作对手事件 | 比较可见正文；空页、访问验证和失败保留原快照；事件需人工解释 |
| 监控事件跨清单混读、重复启动覆盖历史 | 清单隔离、原子保存、写锁、事件去重与启动保护 |
| 安装版缺经验数据，调度丢失工作区 | 经验记录随发行包安装；调度绑定 MKT_HOME，事实包存绝对路径 |
| 源码测试无法证明发行包可用 | Python 3.9/3.11 CI 增加脱离源码目录的 wheel 验收 |

本地验收：1075 项测试通过；显式断开 CDP 测试入口后仍全部通过；demo、doctor self-test、wheel 安装与独立验收通过。浏览器只读检查确认当前 X 登录态，未为验收增加真实发送。

交付边界：发送回执不等于增长或转化；X 指标读数仍需持续校准；结果卡默认生成本地文件；macOS Documents 权限可能阻止 launchd，需要使用已具备目录权限的进程或另行配置系统权限。发布工作流和网站部署的实际状态以 GitHub Actions 为准。
