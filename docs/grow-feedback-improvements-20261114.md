## 本轮代码改进

| 原问题 | 修改后的行为 |
|---|---|
| 指标读取整页，容易把原帖或其他回复的互动算给自己 | 根据 status ID 匹配文章的时间链接，只读取目标文章；找不到就报告缺失 |
| 采过一次就不再更新；回复原帖与自己帖子 URL 不同，去重失效 | 按目标与日期去重；每天刷新，失败可以重试；保留历史快照 |
| 重复快照被视为多个样本，缺回复数也能凑样本门槛 | 一条帖子一个样本；只按有效回复率样本判断是否可以调整；未知分组不参与调参 |
| 暂存索引用 tweet: 前缀，而复盘用裸 URL，公式与 KOC 归因丢失 | 统一索引键；采集与自己帖子 URL 解析也统一去掉前缀 |
| tick 未接入帖子反馈，用户需要另外运行 metrics / learn | 实跑 tick 自动采集最近七天已发布且有自身 URL 的帖子，生成学习结果并纳入日结果单；dry-run 不触发这项外部读取 |
| 同一批证据多次点 optimize，会重复提高权重 | 证据指纹去重；应用过的建议保持不变，等新反馈。调整后更新供给 brief 文件 |
| KOC 占比参数只写入状态和报告 | 混合候选名单按实际占比分配名额，优先模式仍只选 KOC；不足时补位，最终名单不超过 top |
