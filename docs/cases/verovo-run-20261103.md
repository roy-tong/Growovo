## 三、四周战术：用 Verovo 的真实 Reddit 遭遇演练

Verovo 在 r/SaaS 的真实遭遇：AI 生成内容被 AutoModerator 判 AI 直接删帖。
按四周模型把这条渠道补跑一遍（数据是演练，逻辑是真跑）：

```
触达 62｜被删 12（19%）｜回应 4（6%）｜转私信 0
判定：不通
  被删率 19% 超过 15%：触达方式或人群选错了，换渠道或换写法，不要加大力度
```

**注意判定没有说"再坚持一下"**——被删率超线直接判死，这是设计意图：删帖率高的时候加量只会更快被封。

如果只跑了两周（触达 40 以下），模块会拒绝判定：

```
判定：样本不足
  累计只触达 12 条，低于 40 条的最低样本量；再跑 28 条再判，不要提前下结论
```
