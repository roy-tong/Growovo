# 案例：Verovo —— 一轮完整 GTM 教会 Growovo 的事

> **角色**：ovo 家族的「核验层」（LLM 输出核验）。这个案例的特殊之处：它先于 Growovo 存在，它踩过的坑直接变成了 Growovo 的默认纪律。
> **周期**：2026-08-16 → 2026-10-31（约 2.5 个月全周期复盘）· 当前阶段执行中 · 数据截至 2026-11-02
> **[English version](verovo.en.md)**

## 背景

[Verovo](https://github.com/roy-tong/Verovo)（前身 AgentMeasure / MeteringQA）做 LLM 输出核验。2026 年 8–10 月，它经历了一轮教科书级的 GTM 试错：触达与产能全部打满，商业漏斗全程为零。复盘不是失败报告——**那轮试错产出的对照实验和判死线，比大多数成功案例更有价值**，Growovo 的合规与纪律一节里几乎每一条都能在这份复盘里找到出处。

## 总账（先看诚实的部分）

| 维度 | 数字 |
|---|---|
| 触达规模 | 邮件 ~1,200 封（含一次 449 封事故批）、X 动作 ~900 次 |
| 供给侧产出 | 110+ 工具审计、45+ 已验证 bug、上游合并（审计报告发布时 14 项；此后累计以 [GitHub 搜索](https://github.com/search?q=author%3Aroy-tong+type%3Apr+is%3Amerged) 为准，不手改数字）、5 名外部贡献者、1 项 CI 采用、1 项标准采纳 |
| star | 92 颗购入基线星（已永久剔除出归因）→ 220（2026-11-02 API 实测）；全程自然 star 约 16，其中**仅 2 颗可归因，全部来自交付链**。注意 star/fork 比 22.0，超出常态 5–20 区间（2026-11-02 体检），对外引用这个星数必须带说明 |
| 商业结果 | 0 合格买方对话、0 付费、0 复购 |

## 有对照实验的渠道判读

**判死（自有 A/B，不再回头）：**

| 打法 | 证据 |
|---|---|
| X 高量冷触达 | 约 120 次请求 4 天 0 star / 0 任务 / 0 回流；**同期对照组**（上游交付链）+1 star +1 标准采纳——自家数据，以后不用再争 |
| $990 预付冷邮件 | 40 发 0 回复，过预注册判定线（若真实回复率 5%，40 全零概率 12.9%——判死的是「ICP×报价×渠道」组合，不判死市场） |
| Gmail Web UI 自动化群发 | 449 封空正文事故，通道永久关闭 |
| 买星 | 92+42+~13 颗；fork 率 3.7% 当场暴露——铁律「不刷量永久」 |

**判活（有数字）：**

| 打法 | 证据 |
|---|---|
| 上游交付链（审计→issue→PR→合并） | 唯二可归因自然星都来自它；合并、CI 采用、标准采纳不随 star 波动贬值 |
| 求评式 1:1 邮件 | 209 封 → 6+ 实质回复 ≈ **5.3%**；对照冷问句式 0/26 |
| 免费任务 → 信任 | n=2，机制跑通（74 行审计报告换来复测一致 + 授权公开案例） |

## 这份复盘如何变成 Growovo 的默认值

| Verovo 付出的代价 | Growovo 的固化 |
|---|---|
| 449 封空正文事故 | 回读校验不一致绝不发送；`indeterminate` 不可自动重发，必须人工 `ledger resolve` |
| 规模化冲动反复发作（199 条/日 → 500+/日 → 百条批，每次被证伪） | 一切写操作默认 dry-run；计划 size 超内核日预算直接被 lint 拒收 |
| 买星污染全部前期归因 | 账本把「平台动作成功」与「业务结果」记成两个独立字段；发出去了≠转化 |
| 到线不肯停（A 线烧了 6 周才判死） | 判定线预注册：40 封、10 合格报价、2 周零增长，到线就杀 |
| 「差账号持有者十秒」的动作卡死数周 | 人审是显式闸门（署名 + 指纹 + 有效期），人工动作单列出，不静默等待 |

这不是「我们从失败中学到了」的修辞——是同一条工作流里，代价→机制的逐条映射。

## 当前阶段（×10 激进目标，预注册）

2026-10-31 起，Verovo 按 ovo 家族增长方法论实例化执行正本：目标提升一个数量级（star ≥2,200、≥20 付费客户、≥$25,000，2026-12-31 截止），11/09–13 发射周，**11/14 中检：launch 未成行或未达 +300 star → 年底目标降一档**，触发数据记录在案。正本开头保留一段诚实前提：按现有实测系数（交付链 ~1–3 star/周、冷触达两轮 0 转化），×10 在 9 周内不可达；可达路径（冲榜脉冲 × 规模化分发 × 免费任务漏斗）尚未被本项目验证——跑不动就按降档规则降，不硬凑也不静默改目标。
